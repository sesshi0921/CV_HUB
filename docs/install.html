Install CV_HUB

This guide explains how to build CV_HUB locally and launch both the CLI and GUI. The README stays focused on short setup commands; this page adds more context and troubleshooting notes.

Requirements

CV_HUB is a C++20 application built with CMake. It uses OpenCV for image-processing nodes, GLFW/OpenGL for the GUI, Dear ImGui and imnodes for graph editing, and Python for generated plugin code and ML subprocess nodes.

  • CMake 3.24 or newer
  • A C++20-capable compiler
  • OpenCV core / imgproc / imgcodecs / videoio / photo
  • GLFW and OpenGL for the GUI
  • Python 3 for node generation and Python/ML workers

On macOS with Homebrew, CMake automatically detects brew --prefix and prepends it to CMAKE_PREFIX_PATH.

Build

Use an out-of-tree build directory.

Configure and buildRelease
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release

The build produces the CLI, GUI app bundle, runtime libraries, plugins, and tests. On macOS the GUI is generated as CV_HUB.app with an OS-specific application icon.

Launch

CLI

./build/apps/cvhub/cvhub

macOS GUI

open build/apps/cvhub_gui/CV_HUB.app

On macOS, launch the app bundle. Launching a stale raw executable will not show the app icon or native file picker integration.

Non-bundled platforms

./build/apps/cvhub_gui/CV_HUB

CMake Options

  • CVHUB_BUILD_GUI: build the Dear ImGui graph editor.
  • CVHUB_BUILD_PLUGIN_OPENCV: build the OpenCV plugin.
  • CVHUB_BUILD_PLUGIN_PYTORCH: build the Python/PyTorch plugin.
  • CVHUB_BUILD_TESTS: build tests.
  • CVHUB_FETCH_GUI_DEPS: fetch Dear ImGui and imnodes when CMake packages are not available.

Troubleshooting

OpenCV is not found

Add the OpenCV installation prefix to CMAKE_PREFIX_PATH.

GUI dependencies are missing

GLFW is required. Dear ImGui and imnodes can be fetched automatically when CVHUB_FETCH_GUI_DEPS is enabled.

The app icon does not update on macOS

Launch build/apps/cvhub_gui/CV_HUB.app. Finder and Dock may cache icons, so quit the app and reopen the bundle if needed.
